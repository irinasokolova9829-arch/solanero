# Solanero — пакет для Railway

Полный исходный проект сайта: React + Vite, локальные брендовые изображения, основной экран **Private Route**, графики рынков, Phantom-адрес, статический Node.js-сервер и Dockerfile для Railway.

## Быстрый запуск локально

Требуется Node.js 22 или совместимее.

```bash
npm ci
npm run build
npm start
```

По умолчанию сервер слушает `http://localhost:3000`. На Railway он автоматически использует выданную платформой переменную `PORT` и слушает на `0.0.0.0`.

## Развёртывание на Railway

1. Распакуйте ZIP и отправьте содержимое каталога в GitHub-репозиторий. Либо войдите в Railway CLI, откройте этот каталог и выполните `railway init`, затем `railway up`.
2. В интерфейсе Railway создайте проект через **Deploy from GitHub repo** и выберите репозиторий. Railway автоматически обнаружит `Dockerfile` в корне; он установит зависимости, соберёт сайт и запустит Node-сервер.
3. После успешной сборки откройте настройки службы Railway → **Networking** → **Generate Domain**, чтобы получить публичный HTTPS-адрес. При желании задайте в настройках проверки состояния путь `/healthz`.
4. Проверьте главную страницу `/` и прямой переход `/route`. Сервер отдаёт статические файлы из `dist/` и возвращает SPA `index.html` для клиентского маршрута `/route`, поэтому прямая ссылка и обновление страницы не должны приводить к 404.

В проекте не требуется добавлять ключи API, секреты или базу данных для запуска сайта. Dockerfile намеренно используется вместо `railway.json`: официальная документация Railway сообщает, что прежний Config-as-Code формат устарел, а Railway автоматически использует Dockerfile при его наличии.

## Текущее состояние продукта

**Private Route** — полноценный пользовательский интерфейс для ввода суммы SOL и Solana-адреса. Phantom можно подключить, а его публичный адрес — явно скопировать в поле получателя. Подключение только для чтения: баланс кошелька не запрашивается, подпись и транзакции не отправляются.

Для работающего обмена SOL → XMR → SOL нужен выбранный и проверенный route provider. Сейчас нет источника достоверных котировок или условий исполнения, поэтому поля курса, комиссий, срока доставки и суммы получения намеренно пусты, а отправка формы только проверяет введённые данные. Пул ликвидности, депозит, обмен и вывод через сайт не доступны.

Графики SOL/BTC/XMR запрашивают публичные рыночные данные CoinGecko в браузере. Доступность и частота обновлений зависят от публичного API. Для Phantom требуется браузер с установленным расширением и открытый HTTPS-сайт; расширение обычно не внедряет provider во встроенный iframe Preview.

## Состав архива

В ZIP включены исходники `src/`, изображения `public/assets/`, публичный route manifest, `package.json` и lockfile, Dockerfile, статический сервер и этот файл. Исключены Git-метаданные, локальные зависимости `node_modules/`, собранная папка `dist/` и файлы `.env*`; Docker повторяемо устанавливает зависимости и собирает проект при развёртывании.
